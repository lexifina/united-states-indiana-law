# IC 32-24-3-1. Commencement of action

Sec. 1. If the governor considers it necessary:
  - (1) to acquire property on which to construct public buildings for the state; or
  - (2) to acquire property adjoining state property on which buildings have been erected; the governor may order the attorney general to file an action in the name of the state. The attorney general shall file the action in a court that has jurisdiction in the county in which the property is located. The state's petition must ask that appraisers be appointed to appraise the value of the property considered necessary to be acquired for the public uses of the state.
[Pre-2002 Recodification Citation: 32-11-2-1.]

As added by P.L.2-2002, SEC.9.
