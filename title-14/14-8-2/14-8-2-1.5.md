# IC 14-8-2-1.5. "Acquiescence"

Revisor's Note: This version of section added by P.L.6-2008, SEC.1 defines the term "acquiescence". The following version of this section added by P.L.191-2023, SEC.1 defined the term "affidavit". The following version of this section was repealed by P.L.9-2024, SEC.347 and relocated to IC 14-8-2-3.2 by P.L.9-2024, SEC.348.
Sec. 1.5. "Acquiescence", for the purposes of IC 14-26-2, has the meaning set forth in IC 14-26-2-1.2.

As added by P.L.6-2008, SEC.1.
