# IC 12-7-2.1-235. "Office"

Note: This version of section added by P.L.145-2026, SEC.63, formerly IC 12-7-2-134 as amended by P.L.35-2016, SEC.6. See also following version of this section added by P.L.145-2026, SEC.63, formerly IC 12-7-2-134 as amended by P.L.134-2019, SEC.1.
Sec. 235. "Office" means the following:
  - (1) Except as provided in subdivisions (2) through (5), the office of the secretary established by IC 12-8-1.5-1.
  - (2) For purposes of IC 12-10-13, the meaning set forth in IC 12-10-13-4.
  - (3) For purposes of IC 12-15-13, the meaning set forth in IC 12-15-13-0.4.
  - (4) For purposes of IC 12-17.2-7.2, the meaning set forth in IC 12-17.2-7.2-3.
  - (5) For purposes of IC 12-17.6, the meaning set forth in IC 12-17.6-1-4.

As added by P.L.145-2026, SEC.63.

## IC 12-7-2.1-235. "Office"

Note: This version of section added by P.L.145-2026, SEC.63, formerly IC 12-7-2-134 as amended by P.L.134-2019, SEC.1. See also preceding version of this section added by P.L.145-2026, SEC.63, formerly IC 12-7-2-134 as amended by P.L.35-2016, SEC.6.

  - (4) For purposes of IC 12-15-5-15, the meaning set forth in IC 12-15-5-15(b).
  - (5) For purposes of IC 12-15-5-16, the meaning set forth in IC 12-15-5-16(b).
  - (6) For purposes of IC 12-15-13, the meaning set forth in IC 12-15-13-0.4.
  - (7) For purposes of IC 12-15-13.5, the meaning set forth in IC 12-15-13.5-1.
  - (8) For purposes of IC 12-17.6, the meaning set forth in IC 12-17.6-1-4.

As added by P.L.145-2026, SEC.63.
