# IC 20-32-5.1-3. Indiana's Learning Evaluation Assessment Readiness Network (ILEARN) program

Sec. 3. The Indiana's Learning Evaluation Assessment Readiness Network (ILEARN) program consists of:
  - (1) a statewide assessment described in section 7 of this chapter;
  - (2) optional benchmark assessments described in section 17 of this chapter;
  - (3) requirements to integrate statewide assessment literacy described in section 18 of this chapter; and
  - (4) any programs or policies approved by the state board that are necessary to carry out this chapter.

As added by P.L.242-2017, SEC.41. Amended by P.L.192-2018, SEC.36.
