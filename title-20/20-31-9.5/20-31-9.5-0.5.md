# IC 20-31-9.5-0.5. State board approval of contracts; direction of the department

Sec. 0.5. (a) The state board must approve any contracts necessary to implement IC 20-31-9 and this chapter.
- (b) The state board may direct the department to assist the state board with the state board's duties under IC 20-31-9 and this chapter, including, but not limited to:
  - (1) providing data to the state board that the state board determines is necessary to execute such duties; and
  - (2) entering into contracts as determined by the state board.

As added by P.L.223-2015, SEC.7.
