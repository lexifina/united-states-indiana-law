# IC 16-38-7-10. Data format and criteria

Sec. 10. (a) An entity required to submit data under section 8 of this chapter shall submit data to the registry by direct data entry or by electronic data transfer using an .xml format and data scheme that is based on the trauma data dictionary.
- (b) A hospital shall submit data to the registry using the criteria in the trauma data dictionary.
- (c) A rehabilitation hospital shall submit data to the registry using the rehabilitation hospital registry data dictionary.
- (d) An emergency medical services provider shall submit data to the registry using the most current version of the National EMS Information System data elements and the criteria in the Indiana EMS Data Dictionary.

As added by P.L.96-2026, SEC.24.
