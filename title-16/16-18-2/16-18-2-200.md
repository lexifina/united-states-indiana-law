# IC 16-18-2-200. "Legislative body"

Sec. 200. (a) Except as provided in subsections (b) and (c), "legislative body" has the meaning set forth in IC 36-1-2-9.
- (b) For purposes of IC 16-20-1-21.5, "legislative body" has the meaning set forth in IC 16-20-1-21.5(c).
- (c) For purposes of IC 16-20-5.5, "legislative body" has the meaning set forth in IC 16-20-5.5-1.
[1993 Recodification Citation: New.]

As added by P.L.2-1993, SEC.1. Amended by P.L.219-2021, SEC.2.
