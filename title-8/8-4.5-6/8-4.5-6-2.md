# IC 8-4.5-6-2. Places to file

Sec. 2. Before a corridor in any part of a county may be converted for use as a recreational trail, a responsible party must file the information required by section 3 of this chapter with the following:
  - (1) The department of natural resources.
  - (2) If any part of the recreational trail is intended to be located in a municipality, with the executive of the municipality.
  - (3) If any part of the recreational trail is intended to be located on property not within a municipality, with the county executive of any county in which the recreational trail is intended to be located.

As added by P.L.40-1995, SEC.3. Amended by P.L.158-1999, SEC.16.
