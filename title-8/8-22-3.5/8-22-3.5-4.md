# IC 8-22-3.5-4. Definitions

Sec. 4. As used in this chapter, the following terms have the meanings set forth in IC 6-1.1-1:
  - (1) Assessment date.
  - (2) Assessed value or assessed valuation.
  - (3) Tangible property.
  - (4) Taxing district.
  - (5) Taxing unit.

As added by P.L.86-1991, SEC.1.
