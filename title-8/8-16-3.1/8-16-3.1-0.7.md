# IC 8-16-3.1-0.7. "Double tracking"

Sec. 0.7. As used in this chapter, "double tracking" means a railway running two (2) bidirectional tracks. The term includes a railway:
  - (1) with a double track that can be signaled to run in a single direction; and
  - (2) with a double track that can be signaled into one (1) track to provide clearance as needed.

As added by P.L.229-2017, SEC.32; P.L.248-2017, SEC.2.
