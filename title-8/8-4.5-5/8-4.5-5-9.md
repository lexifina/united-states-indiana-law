# IC 8-4.5-5-9. Waiver for acquisition of real property

Sec. 9. (a) Notwithstanding section 7(1) of this chapter, if there is extreme urgency involving real property acquisition, the board may grant an applicant's request for a waiver to acquire the real property immediately.
- (b) A request for a waiver under subsection (a) must be in writing and include all of the following:
  - (1) Justification for the urgency of the acquisition.
  - (2) A description of the real property to be acquired.
  - (3) A county map showing the location of the real property to be acquired.

As added by P.L.40-1995, SEC.3.
