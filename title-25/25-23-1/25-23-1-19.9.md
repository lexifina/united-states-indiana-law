# IC 25-23-1-19.9. INSPECT program report in patient's medical file

Sec. 19.9. (a) This section does not apply to certified registered nurse anesthetists.
- (b) An advanced practice nurse may include a report from the INSPECT program in a patient's medical file. Any disclosure or release of a patient's medical file must be in compliance with IC 35-48-7-11.1.

As added by P.L.82-2016, SEC.6.
