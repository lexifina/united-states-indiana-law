# IC 25-22.5-13-7. INSPECT program report in patient's medical file

Sec. 7. A physician may include a report from the INSPECT program in a patient's medical file. Any disclosure or release of a patient's medical file must be in compliance with IC 25-26-24-19.

As added by P.L.82-2016, SEC.4. Amended by P.L.51-2019, SEC.6.
