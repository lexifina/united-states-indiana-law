# IC 25-42-3-6. Application for single state license

Sec. 6. (a) Individuals not residing in a party state may apply for a party state's single state license as provided under the laws of each party state. However, a single state license granted to the individual will not be recognized as granting the privilege to practice nursing in any other party state.
- (b) This compact does not affect the requirements established by a party state for the issuance of a single state license.

As added by P.L.135-2019, SEC.5.
