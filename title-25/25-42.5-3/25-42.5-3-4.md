# IC 25-42.5-3-4. Non-resident single state license

Sec. 4. Individuals not residing in a member state shall continue to be able to apply for a member state's single state license as provided under the laws of each member state. However, the single state license granted to these individuals shall not be recognized as granting a privilege to practice professional counseling in any other member state.

As added by P.L.98-2023, SEC.2.
