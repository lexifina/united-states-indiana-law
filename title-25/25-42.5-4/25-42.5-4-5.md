# IC 25-42.5-4-5. Home state license restored

Sec. 5. If a home state license is encumbered, the licensee shall lose the privilege to practice in any remote state until all the following occur:
  - (1) The home state license is no longer encumbered.
  - (2) The licensee has not had any encumbrance or restriction against any license or privilege to practice within the previous two (2) years.

As added by P.L.98-2023, SEC.2. Amended by P.L.9-2024, SEC.472.
