# IC 25-43-5-3. Relocation to nonmember state; relocation from nonmember state to member state

Sec. 3. If an occupational therapist or occupational therapy assistant changes primary state of residence by moving from a member state to a nonmember state, or from a nonmember state to a member state, the state criteria shall apply for issuance of a single state license in the new state.

As added by P.L.21-2023, SEC.1.
