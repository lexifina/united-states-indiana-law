# IC 25-17.6-3-3. Code of professional conduct

Sec. 3. (a) The board may by rule adopt or amend a code of professional conduct for licensed professional geologists.
- (b) If the board adopts or amends a code of professional conduct under subsection (a), the board shall mail a copy of the code and any amendments to the code to all persons listed on the roster described in section 10 of this chapter.
- (c) A mailing under this section constitutes service for the purposes of this article.

As added by P.L.161-1996, SEC.2. Amended by P.L.17-1999, SEC.9.
