# IC 25-42.5-5-3. Relocation between non-member state and member state

Sec. 3. If a licensed professional counselor changes primary state of residence by moving from a member state to a nonmember state, or from a nonmember state to a member state, the state criteria shall apply for issuance of a single state license in the new state.

As added by P.L.98-2023, SEC.2.
