# IC 25-43-4-6. Effect of encumbrance on home state license

Sec. 6. If a home state license is encumbered, the licensee shall lose the compact privilege in any remote state until the following occur:
  - (1) The home state license is no longer encumbered.
  - (2) Two (2) years have elapsed from the date on which the home state license is no longer encumbered in accordance with subdivision (1).

As added by P.L.21-2023, SEC.1.
