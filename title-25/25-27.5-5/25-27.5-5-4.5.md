# IC 25-27.5-5-4.5. INSPECT program report in patient's medical file

Sec. 4.5. A physician assistant may include a report from the INSPECT program in a patient's medical file. Any disclosure or release of a patient's medical file must be in compliance with IC 25-26-24-19.

As added by P.L.82-2016, SEC.10. Amended by P.L.51-2019, SEC.9.
