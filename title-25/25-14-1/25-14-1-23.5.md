# IC 25-14-1-23.5. INSPECT program report in patient's medical file

Sec. 23.5. A dentist may include a report from the INSPECT program in a patient's medical file. Any disclosure or release of a patient's medical file must be in compliance with IC 25-26-24-19.

As added by P.L.82-2016, SEC.2. Amended by P.L.51-2019, SEC.5.
