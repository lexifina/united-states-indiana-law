# IC 23-2.5-1-32. "Redacted"

Sec. 32. "Redacted", with respect to personal information, means that the personal information has been altered or truncated so that not more than the last four (4) digits of:
  - (1) a Social Security number;
  - (2) a driver's license number;
  - (3) a state identification number; or
  - (4) an account number;
are accessible as part of the personal information.

As added by P.L.175-2019, SEC.2.
