# IC 36-12-3-3. Authority of library board

Sec. 3. The library board shall govern and set policy for all the affairs of the public library. The library board may:
  - (1) make rules for the discharge of the library board's responsibilities; and
  - (2) manage and insure all real and personal property belonging to the public library.
[Pre-2005 Elementary and Secondary Education Recodification Citation: 20-14-3-2.]

As added by P.L.1-2005, SEC.49.
