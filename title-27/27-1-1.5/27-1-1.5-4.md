# IC 27-1-1.5-4. Reference to United States Code; reference to Code of Federal Regulations

Sec. 4. Except as otherwise provided in this title, the following apply to a reference in this title to a federal statute or regulation:
  - (1) A reference that contains a citation to the:
    - (A) United States Code location of the federal statute; or
    - (B) Code of Federal Regulations location of the federal regulation;
is a reference to the federal statute or regulation as in effect on January 1, 2018.
  - (2) A reference that contains a citation to:
    - (A) the Public Law by which the federal statute was enacted; or
    - (B) the issue of the Federal Register that contains the final language of the federal regulation;
is a reference to the federal statute or regulation as in effect on the date of the Public Law or issue of the Federal Register.

As added by P.L.124-2018, SEC.1.
