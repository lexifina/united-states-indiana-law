# IC 27-1-1.5-3. Reference to Indiana Administrative Code

Sec. 3. Except as otherwise provided in this title, a reference in this title to an Indiana administrative rule is a reference to the rule:
  - (1) as added to the Indiana Administrative Code; or
  - (2) as amended;
whichever occurred most recently.

As added by P.L.124-2018, SEC.1.
