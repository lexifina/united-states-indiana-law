# IC 27-2-23-6. "Death master file match"

Sec. 6. As used in this chapter, "death master file match" means the result of a search of a death master file that indicates a match of a person's name with the person's:
  - (1) Social Security number; or
  - (2) date of birth.

As added by P.L.90-2014, SEC.1.
