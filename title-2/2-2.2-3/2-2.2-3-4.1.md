# IC 2-2.2-3-4.1. Status of current codes of ethics; expiration of section

Sec. 4.1. (a) The code of ethics in effect on July 1, 2015, remains the code of ethics in effect until it is amended as provided in section 4 of this chapter.
- (b) This section expires July 1, 2017.

As added by P.L.123-2015, SEC.2.
