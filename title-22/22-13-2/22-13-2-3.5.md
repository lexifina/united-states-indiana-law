# IC 22-13-2-3.5. Rules requiring the installation of automatic fire sprinkler systems prohibited

Sec. 3.5. (a) The following may not adopt rules requiring the installation of an automatic fire sprinkler system in a Class 2 structure:
  - (1) The commission.
  - (2) Another state agency.
- (b) A political subdivision may not adopt an ordinance or other regulation requiring the installation of an automatic fire sprinkler system in a Class 2 structure.

As added by P.L.104-2018, SEC.5.
