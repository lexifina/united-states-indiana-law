# IC 34-55-2-5. Return of execution by sheriff; copy of recognizance on execution docket

Sec. 5. The sheriff, having taken the bail, shall immediately return the execution, with the sheriff's actions noted on the execution to the clerk's office. The clerk shall copy the recognizance in the execution docket. The recognizance has the same force as if taken by the clerk.
[Pre-1998 Recodification Citation: 34-1-35-6.]

As added by P.L.1-1998, SEC.51.
