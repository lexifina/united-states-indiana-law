# IC 34-55-7-3. Neglect or refusal of sheriff to return execution; liability

Sec. 3. If a sheriff neglects or refuses to return any execution as required by law, or makes a false return on the execution, the sheriff is liable for the amount the sheriff might and should have levied by virtue of the execution.
[Pre-1998 Recodification Citation: 34-1-40-3.]

As added by P.L.1-1998, SEC.51.
