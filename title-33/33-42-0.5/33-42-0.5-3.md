# IC 33-42-0.5-3. "Appearance" or "appear"

Sec. 3. "Appearance" or "appear", with respect to a notarial act, refers to an individual's presence before a notarial officer by:
  - (1) being:
    - (A) physically present before the notarial officer;
    - (B) able to interact with the notarial officer; and
    - (C) able to physically exchange tangible credentials or other documentation with the notarial officer; or
  - (2) the use of audio visual communication.

As added by P.L.59-2018, SEC.10.
