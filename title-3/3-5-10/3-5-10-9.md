# IC 3-5-10-9. District boundary description prevails over conflicting map

Sec. 9. If a conflict exists between:
  - (1) a map showing the boundaries of a district; and
  - (2) a description of the boundaries of that district set forth in the plan;
the district boundaries are the description of the boundaries set forth in the plan, not the boundaries shown on the map, but only to the extent there is a conflict between the description and the map.

As added by P.L.169-2022, SEC.2.
