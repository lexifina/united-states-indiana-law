# IC 3-7-36-15. Absent uniformed services voter; residence of spouse

Sec. 15. Notwithstanding IC 3-7-13-1(3), as set forth in 50 U.S.C. 4025, a spouse described in IC 3-5-2-1.5(4) may elect to use the same residence as the member described in IC 3-5-2-1.5(4), regardless of the date on which the marriage of the spouse and the member occurred.

As added by P.L.240-2025, SEC.13.
