# IC 3-11-2-12.3. Arrangement of ballot so that all candidates for the same office appear on the same ballot page or screen

Sec. 12.3. (a) This section does not apply to a political party office printed on a primary ballot.
- (b) A ballot must be arranged so that all candidates for the same office appear on the same page or screen of the ballot.

As added by P.L.227-2023, SEC.68. Amended by P.L.153-2024, SEC.10.
