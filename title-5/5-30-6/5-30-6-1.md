# IC 5-30-6-1. Request for proposals; design criteria package

Sec. 1. (a) If a separate notice of request for qualifications is issued under IC 5-30-5-1(a), the public agency shall issue a request for proposals to the potential design-builders selected under IC 5-30-5-6.
- (b) Each request for proposals must contain a design criteria package.
- (c) If a public project is a controlled project (as defined in IC 6-1.1-20-1.1) for which a referendum is to be held, a request for proposals may not be issued until after the public agency proposing the controlled project has completed the procedures described in IC 6-1.1-20-3.6.

As added by P.L.74-2005, SEC.1. Amended by P.L.166-2011, SEC.8.
