# IC 5-14-3.5-6. State agencies providing required data to state comptroller

Sec. 6. To the extent any information required to be in the data base is collected or maintained by a state agency or state educational institution, the state agency or state educational institution shall provide that information to the state comptroller for inclusion in the data base.

As added by P.L.172-2011, SEC.15. Amended by P.L.177-2013, SEC.2; P.L.9-2024, SEC.151.
