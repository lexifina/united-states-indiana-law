# IC 5-1.3-3-13. Exemption from taxation

Sec. 13. All property of the IFA, the NWIRDA, or the NICTD constituting a rail project is public property devoted to an essential public and governmental function and purpose and is exempt from all taxes and special assessments of the state or any political subdivision.

As added by P.L.189-2018, SEC.26.
