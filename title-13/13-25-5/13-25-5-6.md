# IC 13-25-5-6. Application fee; rejected application

Sec. 6. (a) If an applicant's application is rejected under section 5 of this chapter because the application is incomplete, the applicant may submit a completed application without submitting an additional application fee.
- (b) If an applicant's application is rejected and the applicant:
  - (1) does not appeal the rejection; or
  - (2) loses an appeal concerning the rejection;
the department shall refund the unexpended part of the applicant's application fee.

As added by P.L.1-1996, SEC.15. Amended by P.L.135-2026, SEC.273.
